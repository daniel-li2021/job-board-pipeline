# Candidate Search & Matching Profile

## Goal
Use broad recall at discovery time, then rank jobs by actual evidence from the job description and the most relevant resume. Prioritize responsibilities and required qualifications over keyword overlap.

## Target Role Families

### Software / Backend / Platform
Software Engineer / SDE, Backend Engineer, Full-Stack Engineer, Platform or Infrastructure Engineer, Cloud / Distributed Systems Engineer, Data Platform Engineer, and software-oriented Data Engineer.

### AI / ML / Applied AI
AI Engineer, Applied AI Engineer, ML Engineer, AI/ML Platform or Infrastructure Engineer, LLM / Generative AI Engineer, Retrieval / Search Engineer, Agentic AI Engineer, and Forward Deployed / Solutions roles when the work is hands-on software or AI implementation.

## Seniority
Prefer New Grad, Early Career, Entry Level, Engineer I / SWE I / SDE I, Associate, and roughly 0–3 years.

Do not automatically reject 3–5 years if the responsibilities and required skills are a strong match. Strongly down-rank Senior / Staff / Principal / Lead roles and roles requiring 5–7+ years unless the actual scope is clearly early-career compatible.

## Hard Constraints
Reject or heavily down-rank:
- U.S. Citizen-only or security-clearance requirements.
- Roles restricted to candidates who already hold or must obtain a clearance.
- Non-U.S. roles for a U.S.-only search.
- Hardware-first roles such as FPGA / RTL / ASIC / board design / electrical engineering unless the actual work is clearly software/platform focused.

## Resume Routing
- SWE / Backend / Full Stack / Platform / Infrastructure / Data Platform → `resume_swe.md`
- AI Engineer / Applied AI / LLM / RAG / ML Platform / AI Infrastructure / Retrieval / Agentic AI → `resume_ai.md`
- Mixed or ambiguous roles → compare both and use the resume with stronger evidence.

## Matching Policy
- Optimize discovery for recall; optimize ranking for evidence-based fit.
- Judge title, responsibilities, required qualifications, and seniority together.
- Required qualifications matter more than preferred / nice-to-have qualifications.
- Prefer demonstrated experience over keyword overlap.
- A missing preferred skill is not a major gap; a missing core requirement is.
- Keep technical FDE / Solutions Architect / implementation roles when hands-on; down-rank clearly sales / presales / quota-oriented roles.
- Freshness and verified official URLs affect application priority, not the underlying fit score.
